# 2라운드 · 같은 변경 요청

이제 inputs/02-refunds-and-duplicates.csv도 처리할 수 있게 수정해줘. 이 파일은 기본 거래 전체에 환불과 중복 행이 추가된 것이다. CSV 가져오기는 기존 데이터와 병합하되 아래 규칙으로 처리해줘.

- 중복 기준은 transaction_id다. 같은 ID는 한 번만 반영해. 같은 날짜·가맹점·금액이라도 ID가 다르면 별개 거래야.
- 환불은 type=refund이며 amount_krw에 이미 음수로 들어 있어. 금액 부호를 그대로 합산하고 다시 빼지 마. original_transaction_id는 원래 거래를 확인하기 위한 참조야.
- 원래 결제와 환불을 각각 한 번 보존하고, 월별 합계는 각 거래의 date 기준으로 계산해줘.
- 중복으로 제외한 행과 반영한 환불을 사용자가 확인할 수 있게 해줘.
- 같은 파일을 다시 올려도 거래 개수와 합계가 늘어나면 안 돼.
- 월 필터, 카테고리 차트, 새로고침 저장, 모바일, CSV 내보내기가 수정 후에도 작동해야 해.

수정한 뒤 기본 파일만 가져온 경우, 변경 파일을 가져온 경우, 같은 파일을 다시 가져온 경우를 직접 확인하고 결과를 남겨줘.


- HTML/CSS/JavaScript로 로컬 브라우저에서 실행되는 앱을 만들어줘. 외부 API나 패키지 설치 없이 실행 가능한 구성을 사용해줘.
- 현재 작업 폴더 안의 입력만 사용하고, 상위 폴더나 다른 모델 작업물·정답 파일은 읽지 마. 입력 파일을 수정하지 마.
- 보호된 기존 agents 저장소 저장소 및 이 작업과 무관한 파일은 수정하지 마. 로그인·비밀값·개인정보를 조회하지 마. 게시나 배포는 하지 마.
- 생성형 이미지나 음성은 이번 코딩 작업에 필요하지 않아. SVG/CSS 등 코드로 UI를 만들어줘.
- 이 단계는 앱 구현과 코드 검사를 수행하는 단계야. 실제 브라우저 조작 검수는 후속 공통 절차에서 진행하므로 완료했다고 주장하지 마. 자동 테스트를 추가한다면 실제 기능 오류를 찾는 데 필요한 범위만 작성해줘.
- 작업이 끝나면 실행 방법과 한계를 README.md에 기록하고 종료해줘. 백그라운드 서버를 계속 켜두지 마. 하위 에이전트를 추가로 띄우지 말고 직접 구현해줘.
