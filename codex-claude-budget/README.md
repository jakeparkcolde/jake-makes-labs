# 같은 가계부, 수정까지 비교하기

제이크메이크스 1편 실습 자료. 모든 거래는 가상 데이터입니다.

## 실행

`code/baseline-v1`은 첫 결과, `code/revised-v1`은 같은 변경 요청 후 결과입니다. 각각 `codex-astra`와 `claude-fable` 폴더를 포함합니다. 원하는 폴더로 이동해 `python3 -m http.server 8000`을 실행하고 `http://localhost:8000`에서 엽니다. 서로 다른 앱은 별도 포트 또는 브라우저 프로필로 실행하면 저장 데이터를 구분하기 쉽습니다. 서버 종료는 Ctrl+C입니다. 패키지 설치와 실제 은행 연결은 필요하지 않습니다.

## 같은 비교를 해보기

1. 빈 폴더를 두 개 만들고 각각에 `inputs/01-basic.csv`를 넣습니다.
2. 각자의 코딩 도구를 해당 폴더에서 열고 `INITIAL-REQUEST.txt`를 전달합니다.
3. 첫 결과를 별도 복사해 보존한 뒤, 같은 대화에 `inputs/02-refunds-and-duplicates.csv`와 `REVISION-REQUEST.txt`를 전달합니다.
4. 아래 정답과 `VERIFICATION.md`를 사용해 직접 확인합니다.

첫 파일: 전체 343,850원 / 16건 / 8월 136,200원 / 9월 207,650원.
변경 후: 전체 242,350원 / 18건 / 8월 123,700원 / 9월 118,650원.
다시 올리기: 거래 수와 금액 그대로. S05와 S09는 다른 거래이며 둘 다 보존합니다.

## 비교 범위

2026-09-16 한 번의 과제 실행 기록입니다. Codex CLI 0.154.0에서 gpt-6-astra를 지정했고, Claude Code 2.1.273에서 claude-fable-5-1을 사용했습니다. 두 도구의 High 설정은 같은 연산량을 보장하지 않습니다. 기존 구독 인증을 사용했으며 API 비용을 계산한 실험이 아닙니다. 같은 맥에서 실행했고 제품별 기본 시스템과 도구가 다르므로 순수 모델 성능 순위로 해석하지 않습니다.

요청문은 실제 전달본에서 개인 홈 경로 한 곳만 일반적인 표현으로 바꿨습니다. 앱 코드는 모델이 만든 결과를 그대로 보존했습니다. 제작자가 앱 코드를 대신 수정하지 않았습니다. 모델별 README의 테스트는 모델이 작성한 서로 다른 검사이므로 개수를 점수로 비교하지 않습니다.
