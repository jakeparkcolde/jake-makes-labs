# 1라운드 · 같은 가계부 만들기

CSV 파일을 올리면 지출을 정리해 주는 한국어 웹 가계부를 만들어줘.

입력: inputs/01-basic.csv. 모든 거래는 가상 데이터이며 통화는 원화다.
요구사항:
- 처음에는 업로드 안내가 보이고, CSV를 올리면 전체/월별 순지출 합계, 카테고리별 합계와 차트, 거래 목록을 보여줘.
- 월 필터를 바꾸면 합계·차트·목록이 같은 범위로 바뀌어야 해.
- 금액은 쉼표와 원화 단위를 표시하고, 거래 날짜·가맹점·분류를 읽기 쉽게 배치해줘.
- 390px 폭 모바일에서 사용할 수 있어야 해.
- 새로고침해도 업로드한 데이터와 선택한 월을 이 브라우저에서 유지해줘.
- 현재 필터의 거래 내역을 UTF-8 CSV로 내려받을 수 있게 해줘.
- 빈 파일이나 필수 열이 없는 파일에는 이해할 수 있는 오류를 보여줘.

정해진 프로젝트 폴더 안에서만 작업하고, 외부 서비스 가입·결제·실제 은행 연결은 하지 마. 샘플 파일은 수정하지 마. 필요한 실행 방법을 남기고, 가능한 코드 검사를 수행하고 아직 브라우저에서 확인하지 못한 사항을 밝혀줘. 디자인은 자유롭게 하되 읽기 쉽고 실용적으로 만들어줘.


공통 실행 조건:
- HTML/CSS/JavaScript로 로컬 브라우저에서 실행되는 앱을 만들어줘. 외부 API나 패키지 설치 없이 실행 가능한 구성을 사용해줘.
- 현재 작업 폴더 안의 입력만 사용하고, 상위 폴더나 다른 모델 작업물·정답 파일은 읽지 마. 입력 파일을 수정하지 마.
- 보호된 기존 agents 저장소 저장소 및 이 작업과 무관한 파일은 수정하지 마. 로그인·비밀값·개인정보를 조회하지 마. 게시나 배포는 하지 마.
- 생성형 이미지나 음성은 이번 코딩 작업에 필요하지 않아. SVG/CSS 등 코드로 UI를 만들어줘.
- 이 단계는 앱 구현과 코드 검사를 수행하는 단계야. 실제 브라우저 조작 검수는 후속 공통 절차에서 진행하므로 완료했다고 주장하지 마. 자동 테스트를 추가한다면 실제 기능 오류를 찾는 데 필요한 범위만 작성해줘.
- 작업이 끝나면 실행 방법과 한계를 README.md에 기록하고 종료해줘. 백그라운드 서버를 계속 켜두지 마. 하위 에이전트를 추가로 띄우지 말고 직접 구현해줘.
